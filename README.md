## Overview

Smart Healthcare is an AI-inspired resource allocation system designed for hackathon demos. It includes:
- responsive landing experience
- emergency request panel
- admin login and hospital bed controls
- ambulance assignment simulation
- analytics with demand prediction
- Node.js/Express backend with optional MongoDB support


## Features

- Landing page with a modern dark theme and animated hero section
- Emergency form with patient details, location, severity, and bed type
- Smart hospital scoring based on distance, capacity, and load
- Automatic nearest ambulance assignment and tracking
- Admin authentication and live bed inventory management
- Demand prediction graph for the next 2 hours
- Analytics dashboards with live metrics and charts
- Mock data and simulated real-time updates for presentation

## Notes for Hackathon
- The app is ready for demo mode with mock live updates.
- Backend is included and can be extended with MongoDB.
- Map placeholders can be replaced with Google Maps or OpenStreetMap in the future.
- Adding WebSockets will enable true real-time tracking.
